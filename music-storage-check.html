WHATEVER / PRIVATE SOURCES

音乐源码保护

使用你已经登录的管理员账号，核对 Supabase 私有 Storage 中的真实音乐文件，先备份，再修改。不涉及聊天记录、共同记忆和基础样式。

仅限已登录管理员 · 原文件覆盖关闭

01 · 核对原始文件

从 Supabase 私有桶读取原文件大小和 SHA-256，不读取假数据。

手机可直接选择「直接下载合并版 ZIP」，无需另开离线 HTML 网页；生成过程只在浏览器中运行，不会写入 Supabase。

如果提示未登录：请使用同一个浏览器打开 Whatever 首页并登录，然后返回本页。PWA、ChatGPT 内置浏览器与普通浏览器可能不共享登录状态。

02 · 创建可验证的备份

每份原文件在 Supabase 私有桶创建单独备份，并重新读取校验内容哈希。不会覆盖原件。

准备就绪。请先点击「验证管理员并检查」。
源文件覆盖权限默认锁定；此页面没有覆盖或删除按钮。

03 · 定点修复原音乐源码

先完成四份私有备份，再选择经校验的修复包。仅允许预审的两份源码及其精确 SHA-256，其他内容全部拒绝。

尚未载入修复包。music.css、music-markup.js 和 base.css 不会被修改。

只有你手动点击才会向 Supabase 写入；服务器会再次创建私有备份、验证原 SHA-256、审核新 SHA-256，并在写回后重新读取校验。其他文件的任意覆盖权限仍锁定。
