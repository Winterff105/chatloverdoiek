## 安装步骤

1. 把 `assets/`、`music/`、`js/apps/music.js` 按对应路径放进网站仓库根目录；不要把 `music/` 下的三个 JS/CSS 文件放入 `protected-scripts` 才能加载，因为本包目前使用的是 `/music/index.html` 公共路径。
2. 在网站主页面确保已加载 `<script src="/js/apps/music.js"></script>`。可加在 `index.html` 现有核心加载逻辑后面，或用 `app-manager.js` 懒加载。
3. 在已有音乐 App 的打开分支中，把音乐界面挂载到主 App 容器：

```js
// 例：现有 app-manager.js 已决定打开音乐 App 后
window.WhateverMusicApp.mount(document.getElementById('appWindow'));
```

4. 在现有 app-manager 的关闭分支中调用：

```js
window.WhateverMusicApp.close({ remove: true });
```

本包页面左上角添加了返回箭头。点击会调用 `parent.WhateverMusicApp.close()` 和 `parent.closeApp()`，尝试返回小手机桌面。

## 将“一起听”的 AI 设置与主设置页绑定（重要）

`music-api.js` 不另存任何模型、API URL、API 密钥或采样参数，而是每次发消息时向宿主环境读取配置。它优先读取主 App 传入的 `getSettings()`；如果现有设置模块有统一 AI 调用函数，更推荐一并接入 `callAI()`，复用原本的提供商兼容性、代理与错误处理。

```js
// 以下是桥接接口的用法。根据你的真实 settings.js 实现，换成“设置页当前生效”的对象和 API 调用函数：
window.WhateverMusicApp.configure({
  getSettings: () => {
    // return settingsPage.getCurrentAPIConfig(); // ← 此方法名只是示意，尚未读取到真实 settings.js
    return window.myExistingApiConfig;             // ← 示例占位，请接你项目真实配置
  },
  // 对于 Gemini/Claude/私有代理等非 OpenAI 兼容接口，接入现有统一 AI 请求函数：
  // callAI: ({ messages, settings, config, purpose }) => yourExistingAIClient(messages, settings)
});
```

标准化支持从设置继承：`baseURL/baseUrl/apiUrl`、`apiKey`、`model`、`temperature`、`top_p/topP`、`max_tokens/maxTokens`、`frequency_penalty`、`presence_penalty`、`systemPrompt`、以及自定义请求 headers。不设置某个采样参数时不会强行覆盖主设置的默认值。

如果已有设置模块暴露 `getCurrentAPIConfig`、`getActiveAPIConfig`、`getApiSettings`、`getAPISettings` 等方法，会尝试自动读取；也兼容几个常见 `localStorage` 配置键，**但由于当前真正的设置模块在私有 Storage 中，没有读到精确字段名，因此自动识别不是百分之百保证**。可以在打开音乐页后，在控制台执行：

```js
await MusicApiBridge.getStatus()
// 返回配置来源、模型、接口地址、是否有 API Key（不会返回密钥内容）
```

若找不到配置，一起听仍能使用原 UI，但不会伪造 API 回复；会提示缺少设置/桥接。建议接通主 App `callAI` 再正式上线。

## 原版逻辑保留情况

- 热门唱片柜、网易云热榜、搜索、音源播放与备用音源、歌词、评论、收藏、歌单导入、网易云登录和账号界面等原代码均保留。
- 原版“一起听”的气泡、虚拟恋人数据结构、假消息和随机选歌实现仍保留在 `music.js` 中，但 `music-api.js` 安装 transport 后不再调用随机回复；“恋人聊天”和“TA 选歌”改为向已配置的 AI 发请求，AI 选歌必须匹配当前列表的真实歌曲 ID。
- 由于网易云 API 是第三方站点，实际可用性、版权音源和浏览器 CORS 无法在此离线保证。
- 音乐后台播放/主 App 设置 API 的跨模块生命周期与现有 `app-manager.js` 的真正兼容性，需要上传/读取该私有模块内容后做联调。
