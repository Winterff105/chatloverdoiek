# Chérie Music · 苦临潭小手机接入说明

此分支把用户提供的 `abcd(8).html` 拆成 CSS / JS，保留原视觉与既有功能，接到 Whatever 小手机。

## 文件位置

- `/assets/changpianmoren.jpg`、`/assets/morentouxiang.jpg`、`/assets/musicbjt.jpg`：三张用户原图，无损上传。
- `/music/index.html`、`/music/music.css`：音乐 App 的 HTML 和隔离的 CSS。
- `/music/music.js`：音乐原有业务及 UI 逻辑，服务器校验后下载到浏览器执行。
- `/music/music-api.js`：一起听的 AI 桥接，读取主 App 当前生效的 API 配置。
- `/functions/api/music-core.js`：Cloudflare Pages 后端。验证小手机签名 token 和帐号/设备状态，再使用 `env.ASSETS.fetch` 读取两个 JS 文件并返回。
- `/functions/_middleware.js` 与 `/_routes.json`：拦截 `/music/music.js` 和 `/music/music-api.js` 的公网直接访问，必须走后端带 token 的 `/api/music-core`。
- `/js/apps/music.js`：主应用音乐界面的 iframe 加载器，以及桌面右下角的「音乐」入口。
- `/index.html`：引入音乐入口加载器。
- `/sw.js`：缓存版本号更新到 v14。

## 使用说明

用户正常登录小手机后，桌面右下角会出现「音乐」入口。点击后打开全屏音乐界面；左上角返回按钮关闭音乐界面。

音乐界面需要现有后端环境变量 `TOKEN_SECRET` 和 `SUPABASE_SERVICE_KEY`，与 `/api/login` 等既有接口复用，无需新增秘钥。后端只读取 Supabase 的 `auth_credentials` 和 `member_durations`，没有数据库写入。

### AI 设置

`music-api.js` 每次使用主应用 `window.WhateverMusicApp` 的 `getSettings()` / `callAI()` 桥接，或尝试读取既有全局设置接口和历史 localStorage 设置键。支持 OpenAI 兼容的 API 地址、模型、密钥、temperature、top_p、max_tokens 等。没有单独保存一套 API 配置。API 配置获取不到时会展示明确错误，不会假装成 AI 回复。原有的假逻辑、UI、动画留在源码中作为兼容后备结构。

**尚未完成真实配置联调**：目前私人 Supabase Storage 中的 `settings.js` 源码未通过工具读取，因此没法核实准确的 `getSettings` / `callAI` 实现、Claude/Gemini 等非兼容 API 的调用方式。若希望百分之百复用主设置页，请把真实设置对象或统一 AI 调用函数接入 `WhateverMusicApp.configure({ getSettings, callAI })`。

### 安全边界

Cloudflare 网站直接访问 `/music/music.js` 应返回 404；签名过期、已吊销、设备被踢的用户调用 `/api/music-core` 将被拒绝。代码运行必须最终发送到浏览器，因此客户端不能实现绝对防提取；此外当前 GitHub 仓库是公开的，任何人仍然可以在 GitHub 读取源码。若需要真正保护知识产权，应把源文件迁移至私有代码仓库或私有 Storage 并经后端鉴权返回。
